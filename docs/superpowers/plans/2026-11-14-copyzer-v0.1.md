# Copyzer v0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` to implement this plan task-by-task. Read `ANTIGRAVITY.md`, `STATE.md`, and `HANDOFF.md` first.

**Goal:** Build Copyzer v0.1, a fast, open-source Rust TUI + CLI for Arch Linux & Omarchy to copy iPhone media by Year/Month, Albums (best-effort), or `DCIM/` folders.

**Architecture:** Modular Rust crate (`src/lib.rs` + `src/main.rs`) wrapping `libimobiledevice`/`ifuse` via `std::process::Command` with an RAII `MountGuard`, EXIF/mtime scanning (`kamadak-exif`, `walkdir`), read-only `Photos.sqlite` album lookup (`rusqlite`), atomic `.part` → rename copying, live Omarchy `colors.toml` theming, and a keyboard-first `ratatui` TUI + `clap` CLI.

**Tech Stack:** Rust, `ratatui`, `crossterm`, `clap`, `walkdir`, `kamadak-exif`, `chrono`, `rusqlite` (`bundled`), `toml`, `serde`/`serde_json`, `anyhow`, `filetime`, `tempfile` (dev).

**Spec:** `docs/superpowers/specs/2026-11-14-copyzer-v0.1-design.md`

---

### Task 1: Crate Scaffold & Omarchy Theme (`Cargo.toml`, `src/lib.rs`, `src/theme.rs`)
- **Files:** `Cargo.toml`, `src/lib.rs`, `src/main.rs`, `src/theme.rs`
- **Produces:** `theme::Theme` (`load_default()`, `from_toml_str(&str)`, `from_omarchy_dir(&Path)`).
- **Tests:** Parse valid `colors.toml`, fallback on missing/invalid file.
- **Verify:** `cargo test theme`

### Task 2: iPhone Device & `ifuse` Mount Guard (`src/device.rs`)
- **Files:** `src/device.rs`
- **Produces:** `DeviceStatus`, `DeviceInfo`, `MountGuard`, `doctor_report()`, `detect_device()`, `mount_iphone(udid)`.
- **Tests:** Parse `idevice_id -l`, `ideviceinfo` key-value output, `idevicepair validate` error messages; `MountGuard` drop safety.
- **Verify:** `cargo test device`

### Task 3: DCIM Scanner & Best-Effort Album Reader (`src/scanner.rs`, `src/albums.rs`)
- **Files:** `src/scanner.rs`, `src/albums.rs`
- **Produces:** `MediaItem`, `YearMonthBucket`, `DcimFolderBucket`, `ScanIndex`, `scan_dcim(&Path)`, `AlbumBucket`, `load_albums(&Path, &ScanIndex)`.
- **Tests:** `tempfile` DCIM tree with `.heic`/`.dng`/`.mov`/`.jpg` + non-media ignored; synthetic `Photos.sqlite` test DB + missing/corrupt DB graceful fallback.
- **Verify:** `cargo test scanner` and `cargo test albums`

### Task 4: Atomic Copier (`src/copier.rs`)
- **Files:** `src/copier.rs`
- **Produces:** `CopyProgress`, `CopySummary`, `copy_items(items, dest_root, target_subdir_mode, cancel, progress_tx)`.
- **Tests:** Atomic `.part` → rename, skip duplicate with same name+size, overwrite/rename safety when size differs, cancellation mid-batch.
- **Verify:** `cargo test copier`

### Task 5: CLI & `ratatui` TUI (`src/cli.rs`, `src/tui/mod.rs`, `src/tui/ui.rs`, `src/main.rs`)
- **Files:** `src/cli.rs`, `src/tui/mod.rs`, `src/tui/ui.rs`, `src/main.rs`
- **Produces:** Full `copyzer` binary with `doctor`, `scan`, `copy`, `--mount-dir`, and interactive TUI.
- **Tests:** CLI arg parsing tests + `copyzer doctor --json` & `copyzer scan --mount-dir <tmp> --json` integration check.
- **Verify:** `cargo test` and `cargo clippy --all-targets -- -D warnings`

### Task 6: Arch Linux & Omarchy Packaging (`pkgbuild/PKGBUILD`, `pkgbuild/copyzer.desktop`, `README.md`, `LICENSE`)
- **Files:** `pkgbuild/PKGBUILD`, `pkgbuild/copyzer.desktop`, `README.md`, `LICENSE`
- **Verify:** `desktop-file-validate pkgbuild/copyzer.desktop` (if installed) and `cargo build --release --locked`.
