# Copyzer v0.1 Design Spec

**Date:** 2026-11-14  
**Project:** Copyzer (`copyzer` — English *copy* + Pashto *zer* "fast")  
**Target:** Arch Linux & Omarchy (Hyprland / Wayland), open-source (MIT)  
**Repository:** `/home/batcillos/Work/Github/copyzer`

---

## 1. Goal & Scope (v0.1)

Copyzer v0.1 is a fast, keyboard-first **Rust TUI + CLI** for copying iPhone (including iPhone 16 Pro Max USB-C) photos and videos onto Arch Linux / Omarchy by **whole Years, Months, iPhone Albums (best-effort), or raw `DCIM/` folders**.

**In Scope (v0.1):**
- USB iPhone detection, pairing/trust status reporting, and `ifuse` mount/unmount with RAII cleanup.
- Scanning `DCIM/` into **Year → Month** buckets (EXIF `DateTimeOriginal` with file `mtime` fallback) and raw **`DCIM/` folders**.
- Best-effort **Album** detection via read-only `PhotoData/Photos.sqlite` (`rusqlite`), falling back gracefully to Year/Month & `DCIM/` if iOS restricts database access.
- Atomic, non-destructive bulk copying (`.part` temp file → rename, skip already-copied files by filename + byte size, preserve modification timestamps, never modify iPhone originals).
- Live Omarchy theme integration (`~/.local/state/omarchy/current/theme/colors.toml`) with dark fallback.
- Keyboard-first `ratatui` TUI + headless CLI (`copyzer doctor`, `copyzer scan`, `copyzer copy`).
- Arch Linux `PKGBUILD` + `copyzer.desktop` launcher entry (`Super + Space` in Omarchy).

**Explicitly Out of Scope (v0.1 — future versions):**
- `.HEIC → .JPG` or `.MOV → .MP4` format conversion (deferred to v0.2+).
- Deleting files from the iPhone.
- GUI thumbnail grid.

## 2. Architecture & Module Boundaries

```text
src/
├── main.rs        # CLI/TUI entrypoint, tracing/error exit codes
├── cli.rs         # clap subcommands: TUI (default), doctor, scan, copy
├── device.rs      # idevice_id / ideviceinfo / idevicepair / ifuse + MountGuard
├── scanner.rs     # DCIM traversal, EXIF/mtime date extraction, Year/Month & DCIM buckets
├── albums.rs      # Best-effort read-only PhotoData/Photos.sqlite album mapping
├── copier.rs      # Atomic copy (.part -> rename), duplicate skip, progress events
├── theme.rs       # Omarchy colors.toml parser + dark fallback palette
└── tui/
    ├── mod.rs     # Terminal setup/teardown (crossterm), event loop, state machine
    └── ui.rs      # ratatui layout: header, 3-tab tree/list, progress bar, ? help overlay
```

### Data Flow
1. `device::detect_and_mount()` checks `idevice_id -l` & `idevicepair validate`. If untrusted/locked, surfaces an actionable message (*"Unlock iPhone and tap Trust"*). Otherwise mounts via `ifuse` into a temp directory guarded by `MountGuard` (`Drop` runs `fusermount3 -u` / `umount`).
2. `scanner::scan_dcim(mount_root)` walks `DCIM/` for media extensions (`.heic`, `.jpg`, `.jpeg`, `.png`, `.dng`, `.mov`, `.mp4`, `.aae`), extracts capture date (EXIF → mtime), and builds `ScanIndex` (Years → Months, raw `DCIM` folders).
3. `albums::load_albums(mount_root, &index)` optionally opens `PhotoData/Photos.sqlite` read-only (`SQLITE_OPEN_READ_ONLY | SQLITE_OPEN_NO_MUTEX`) and maps album titles to indexed media files; any error logs a non-fatal warning and leaves `albums` empty with a clear status note.
4. `copier::copy_selection(items, dest_root, tx)` copies each file to `<dest_root>/<bucket>/<filename>.part`, syncs, renames atomically, skips if `<dest_root>/<bucket>/<filename>` already exists with matching byte size, and sends `CopyProgress` events to the TUI/CLI.

## 3. UI & Omarchy Integration

- **Theme:** Reads `accent`, `background`, `foreground`, `color1..color8` from `~/.local/state/omarchy/current/theme/colors.toml`. Falls back to a high-contrast dark palette (`accent: #2563EB` / `#D97706` amber highlight).
- **Keybindings:**
  - `Tab` / `1-3`: Switch view (`Years/Months` | `Albums` | `DCIM Folders`)
  - `Up`/`Down` or `j`/`k`: Navigate
  - `Space`: Toggle selection (whole Year, Month, Album, or Folder)
  - `a`: Select all / none in current view
  - `d`: Edit destination path (default `~/Pictures/Copyzer`)
  - `Enter` / `c`: Start copy
  - `?`: Toggle shortcuts overlay
  - `q` / `Esc`: Quit (unmounts cleanly)
- **Desktop Entry (`pkgbuild/copyzer.desktop`):** Launches `copyzer` inside the user's terminal (`xdg-terminal-exec copyzer` or `alacritty/ghostty -e copyzer`) so it appears in Omarchy's `Super + Space` launcher.
